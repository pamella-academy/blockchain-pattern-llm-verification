# blockchain-pattern-llm-verification

Pipeline de **classificação / verificação de padrões de software blockchain com LLMs** (estágios hierárquicos, checkpoints, prompts, resultados CSV/XLSX).

Liga taxonomia de SLR de padrões em DApps a issues Web3 (amostras e corridas de produção). Inclui `classify.py`, `compare_models.py` e documentação do pipeline.
